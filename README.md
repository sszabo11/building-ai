# ML from scratch in Rust

This folder is designed to teach me from start to finish everything about how to build and design AI models.

## Why rust?

1. I love rust! And I am most comfortable with it. It's elegant, easy to write, run, debug.
2. It's "fast". Even though many things aren't optimized, I get the benefit of it being performant when I need it.

## What I have so far

- Built a MLP from scratch. Impemented forward pass, backprop and everything else.
  - Achieved 100% accuracy on XOR dataset and Iris dataset with classification.
  - Setup token prediction model

- Attached reserviour computer as input to my network as a memory unit.
  - Achieved semi coherent (Dr Seuss) sentences as output from inference.
  - Reserviour showed strong signals of memory compared to standalone NN.
